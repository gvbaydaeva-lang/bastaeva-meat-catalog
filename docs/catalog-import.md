# Передача ассортимента для каталога

Реальные товары добавляются только после отдельного подтверждения. До этого `data/catalog-products.json` должен оставаться пустым (`[]`), а тестовые записи из `tests/fixtures/` не публикуются.

## Как передать данные

Передайте один из вариантов:

- JSON-массив товаров — предпочтительно, если у товара несколько цен, фотографий или назначений.
- CSV с разделителем `;` — удобно для таблицы. Списки в полях `characteristics`, `photos`, `purpose`, `preparation` и `tags` разделяются символом `|`. Ценовые варианты в `priceOptions` записываются как `Название~цена~единица` и разделяются `|`.

Обязательные поля: `slug`, `name`, `categorySlug`, `subcategorySlug`, `description`, `priceOptions`, `composition`, `characteristics`, `photos`, `availability`, `imageLabel`, `purpose`, `tags`.

Допустимые единицы продажи: `kg`, `piece`, `package`. Для цены укажите положительное число. Если цена пока не подтверждена, оставьте `priceOptions` пустым и передайте товар только для согласования.

Допустимые статусы наличия: `in-stock`, `out-of-stock`, `unknown`.

## Фотографии

Для каждого товара создаётся папка:

```text
public/images/products/<categorySlug>/<subcategorySlug>/
```

В поле `photos` указываются локальные пути, например `/images/products/homemade-semi-finished/semi-manti/manti.webp`.

Перед передачей:

1. Используйте только реальные фотографии магазина или материалы, на которые магазин подтвердил права.
2. Не используйте чужие фото, внешние URL и изображения-заполнители.
3. Сохраняйте пропорции и готовьте JPG, PNG или WebP; для обычной карточки желательно не превышать 2000 px по длинной стороне и оптимизировать размер файла.
4. Передайте оригиналы и точные имена файлов вместе с JSON/CSV.

## Проверка до публикации

```bash
npm run catalog:validate -- tests/fixtures/catalog-valid.json
npm run catalog:validate -- путь/к/вашему-файлу.csv
```

Проверка останавливает загрузку при дубликатах товаров, неизвестных категориях, неверных связях категории и подкатегории, ошибках цены или единицы, отсутствии обязательных полей и недоступных фото. Валидатор ничего не записывает в production-файл автоматически.

После проверки подтверждённого файла можно явно подготовить канонический JSON:

```bash
npm run catalog:validate -- путь/к/вашему-файлу.csv --output data/catalog-products.json
```

Без `--output` исходные и production-файлы не изменяются.

Для первой категории передайте подтверждённый список по категории `homemade-semi-finished` («Домашние полуфабрикаты»), соответствующие `subcategorySlug`, цены/единицы, состав, описание, наличие, назначение и фотографии.
