# Подготовка каталога к публикации Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Подготовить локальный каталог из подтверждаемых товарных записей без публикации.

**Architecture:** Production JSON содержит только записи с однозначными названием, ценой и единицей продажи; спорные записи вынесены в отдельный pending JSON. Общие маршруты и компоненты сохраняются, а форматтер цены расширяется для диапазонов.

**Tech Stack:** Next.js App Router, TypeScript, React, Tailwind CSS, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-15-catalog-publication-preparation.md`

## Global Constraints

- Не добавлять неподтверждённые коммерческие сведения или фотографии.
- Не менять дизайн сайта, маршруты, корзину, оплату, админку или интеграции.
- Не выполнять push, merge или публикацию.
- Для production-каталога сохранять точные цены, единицы и диапазоны.

## Review Focus

- Диапазон цен — обе границы видны в карточке и на странице товара; тест: форматтер диапазона.
- Спорная запись — не появляется в production-массиве и маршрутах; тест: список продуктов и slug-проверка.
- Отсутствующая цена — не превращается в ноль; тест: существующее поведение `null` сохраняется.
- Подтверждённое фото — единственное фото привязано к куриным котлетам; тест: источник данных.
- Нейтральная заглушка — карточки без фото используют существующий placeholder; тест: отсутствие фото в production-записях.
