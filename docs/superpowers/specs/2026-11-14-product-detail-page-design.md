# Страница товара — дизайн

## Цель

Подготовить универсальный статический шаблон страницы товара для маршрута `/catalog/[category]/[subcategory]/[product]`, который безопасно работает с подтвержденными данными и не добавляет реальный ассортимент до отдельного согласования.

## Границы

- `products` и `productSlugs` остаются пустыми; фикстуры живут только в тестах.
- Не добавляются корзина, заказ, оплата, Supabase или админ-панель.
- Не меняются шесть категорий, 26 подкатегорий, поиск, фильтры и сортировка.
- GitHub Pages получает только статические маршруты, которые реально существуют в `products`; пустой каталог сохраняет безопасную страницу-заглушку.
- Контакты используют подтвержденный номер `+7 927 590-55-88`; мессенджеры не отображаются без подтвержденных URL.

## Подходы

1. Только серверный компонент: подходит для SEO и статической сборки, но не позволяет надежно сделать галерею, zoom и touch-свайпы.
2. Серверная страница + небольшие клиентские компоненты — выбранный подход: сервер рендерит SEO, breadcrumbs, данные и похожие товары, а клиент отвечает только за интерактив галереи и формирование обращения. Это сохраняет Pages-совместимость и не требует backend.
3. Полностью клиентская страница: дает интерактивность, но ухудшает SEO и увеличивает объем клиентского JavaScript без пользы для текущего проекта.

## Решение

- В `lib/product-detail.ts` будут чистые функции для подписей цены/наличия/единицы, сообщения обращения и выбора похожих товаров.
- `components/product-gallery.tsx` будет client-компонентом: основное фото, миниатюры, кнопки назад/вперед, полноэкранный dialog и touch-свайп. При пустом `photos` показывается существующий `PlaceholderMedia`.
- `components/product-contact-actions.tsx` будет client-компонентом с кнопкой «Уточнить наличие», подтвержденным `tel:` и копированием/показом подготовленного сообщения без отправки данных.
- Страница добавит `generateMetadata`, явные поля только при наличии, безопасную цену `Цену уточняйте`, breadcrumbs, ссылки возврата и блок похожих товаров только при непустом результате.
- Тесты будут использовать локальную fixture с двумя товарами; fixture не импортируется production-кодом.
