# Правила проекта ИП Бастаева А.Д.

- Не добавлять цены, составы, характеристики, остатки, адреса, контакты или фотографии без подтверждённого источника.
- Тестовые данные хранить отдельно от компонентов интерфейса.
- Не создавать корзину, оплату или публичную имитацию админки без отдельного задания.
- Для новых маршрутов использовать общий layout, шапку, подвал и единые UI-компоненты.
- Перед публикацией проверять `npm run typecheck`, `npm run lint`, `npm test` и `npm run build`.
- Сохранять адаптивность, доступность клавиатурной навигации и понятные пустые состояния.
