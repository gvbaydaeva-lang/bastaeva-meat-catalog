# ИП Бастаева А.Д. — сайт-каталог

Рабочий скелет многостраничного сайта мясного магазина на Next.js App Router, TypeScript и Tailwind CSS.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Границы текущего этапа

- Каталог и страницы используют нейтральные placeholder-блоки вместо реальных фотографий.
- Цены, составы, характеристики и наличие намеренно не заполнены: их нужно перенести из подтверждённого ТЗ или согласованного источника.
- Корзина, онлайн-оплата, Supabase, внешние интеграции и публичная админ-панель пока не реализованы.
- Маршрут `/admin` зарезервирован для будущей защищённой панели и сейчас возвращает страницу-заглушку без интерфейса управления.

## Архитектура данных

Тестовые структуры находятся в `lib/data.ts`, модели — в `lib/types.ts`. Компоненты не содержат ассортимент и смогут позднее получать данные из Supabase через отдельный слой доступа.
